# Github Dashboard

## TL;DR

An all-in-one tool that fetched your Github Data to monitor your projects and data. You can view recent actions, commits, pull requests as well as use data analysis for project tracking.

## How-To-Use

Setting up your Github Dashboard is incredibly simple, write your Github username in the username.txt file once you download or clone the repository. After that you can start viewing all your projects and data from Github.

## Tech Stack

Github Dashboard uses HTML, CSS and Javascript (including specific libraries like canvasjs) to talk to the Github API, receive information and dynamically populate the website.
